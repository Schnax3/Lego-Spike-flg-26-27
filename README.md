# Lego-Spike-flg-26-27
Zwei MicroPython-Skripte für die LEGO Education SPIKE App (3.6.1, Python-Modus), die Motorbewegungen an frei wählbaren Ports aufzeichnen, in einer eigenen kompakten Kodierung ausgeben und anschließend synchron auf mehreren Motoren (auch bei unterschiedlicher Bewegungsgröße) wiedergeben
